### 2.1 算法原理

**核心思想**：在训练过程中渐进地增加高斯点的数量，而非一次性达到目标数量。

```python
# 核心逻辑：litegs/training/densify.py
@torch.no_grad()
def get_current_target(self, epoch: int) -> int:
    if epoch < self.densify_params.densify_from:
        return self.init_points_num
    if epoch >= self.densify_params.densify_until:
        return self.target_points_num
    progress = (epoch - self.densify_params.densify_from) / \
               (self.densify_params.densify_until - self.densify_params.densify_from)
    current_target = self.init_points_num + \
                     (self.target_points_num - self.init_points_num) * progress
    return int(current_target)
```

## 三、Enhanced Frustum Culling（增强视锥剔除）

### 3.1 算法原理

**核心思想**：通过添加安全边界（margin）和自适应剔除策略，减少不必要的渲染计算。

```python
# 核心逻辑：litegs/utils/__init__.py
def frustum_culling_aabb_enhanced(frustumplane, aabb_origin, aabb_ext,
                                   margin=0.1, adaptive=True):
    # 基础视锥剔除
    dist_origin = (frustumplane[..., 0:3, None] * aabb_origin).sum(-2) + frustumplane[..., 3]
    dist_ext = (frustumplane[..., 0:3, None] * aabb_ext).abs().sum(-2)
    
    if adaptive:
        # 自适应策略：距离越远，margin 越大
        dist_to_camera = torch.norm(aabb_origin, dim=0, keepdim=True).unsqueeze(1)
        adaptive_margin = margin * (1.0 + dist_to_camera * 0.1)
        dist_ext = dist_ext + adaptive_margin
    else:
        # 固定 margin
        dist_ext = dist_ext + margin
    
    # 可见性判断
    culling = (dist_origin + dist_ext < 0).sum(dim=-1).transpose(0, 1)
    visibility = (culling == 0)
    return visibility
```

**参数配置**：
- `culling_margin`: 0.1（安全边界）
- `adaptive_culling`: True（自适应剔除）
