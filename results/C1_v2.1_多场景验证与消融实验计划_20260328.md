## 任务 2: 消融实验

### 目标

验证每个优化项的独立贡献，确认理论分析的准确性

### 实验设计

#### 实验 1: 只移除 Hessian 近似

**配置**:
```python
dp.use_hessian_approx = False  # 移除 Hessian
dp.use_quantile_normalize = True  # 保持分位数归一化
dp.adaptive_mix_ratio = True  # 保持自适应调度
```

**预期收益**: 0.15 秒/1000 迭代

#### 实验 2: 只使用全局归一化

**配置**:
```python
dp.use_hessian_approx = True  # 保持 Hessian
dp.use_quantile_normalize = False  # 使用全局归一化
dp.adaptive_mix_ratio = True  # 保持自适应调度
```

**预期收益**: 0.45 秒/1000 迭代

#### 实验 3: 只固定混合比例

**配置**:
```python
dp.use_hessian_approx = True  # 保持 Hessian
dp.use_quantile_normalize = True  # 保持分位数归一化
dp.adaptive_mix_ratio = False  # 固定混合比例
dp.importance_mix_ratio = 0.85  # 固定 85/15
```

**预期收益**: 0.01 秒/1000 迭代

#### 实验 4: 组合优化 (v2.1)

**配置**:
```python
dp.use_hessian_approx = False  # 移除 Hessian
dp.use_quantile_normalize = False  # 使用全局归一化
dp.adaptive_mix_ratio = False  # 固定混合比例
dp.importance_mix_ratio = 0.85  # 固定 85/15
```

**预期收益**: 0.61 秒/1000 迭代

### 多场景测试脚本模板

```python
#!/usr/bin/env python
"""
C1 v2.1 多场景测试 - {SCENE_NAME}
"""

import os
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).parent.parent.parent))

from litegs.training.trainer import start
import litegs.config

def run_test(iterations=1000, output_path=None):
    lp, op, pp, dp = litegs.config.get_default_arg()
    
    # C1 v2.1 配置
    dp.use_importance_guided = True
    dp.importance_version = 'v2.1'
    dp.importance_mix_ratio = 0.85
    dp.adaptive_mix_ratio = False
    dp.use_hessian_approx = False
    dp.use_quantile_normalize = False
    
    op.iterations = iterations
    
    # 场景路径
    base_dir = Path(__file__).parent.parent.parent
    lp.source_path = "/mnt/e/Code/LiteGS/data/360_v2/{SCENE_NAME}"
    lp.model_path = str(base_dir / "results" / f"c1_v2.1_{SCENE_NAME}_{iterations}iter")
    
    lp.eval = True
    
    start(lp, op, pp, dp)

if __name__ == "__main__":
    import argparse
    parser = argparse.ArgumentParser()
    parser.add_argument("--iterations", type=int, default=1000)
    parser.add_argument("--output", type=str, default="./results")
    args = parser.parse_args()
    run_test(iterations=args.iterations)
```
