## 关键发现

### 1. 过度工程化是主因

v2.0 引入了过多"理论上更好"但实际上开销很大的改进：
- Hessian 近似 → 增加 150μs/迭代
- 分位数归一化 → 增加 450μs/迭代
- 自适应调度 → 增加 10μs/迭代

### 2. 最大瓶颈是分位数归一化

从 O(N) 到 O(N log N) 的复杂度提升：
```python
# v2.0 分位数归一化 (慢)
q25 = torch.quantile(scores, 0.25)  # 排序
q75 = torch.quantile(scores, 0.75)  # 排序

# v2.1 全局归一化 (快)
min_score = scores.min()  # 线性扫描
max_score = scores.max()  # 线性扫描
```

### 3. 简化即美

- 固定 85/15 比例比自适应调度更简单
- 代码更易维护
- bug 风险更低

## 优化原理

### 为什么有效？

#### 移除 Hessian 近似
- ✅ 减少计算开销
- ⚠️ 理论上略降低准确性
- ✅ 在 1000 迭代中影响不大

#### 回退到全局归一化
- ✅ 大幅减少计算时间 (4 倍快)
- ⚠️ 区分度略低
- ✅ 在短时间训练中差异不明显

#### 固定混合比例
- ✅ 简化代码
- ✅ 减少计算
- ✅ 降低 bug 风险
