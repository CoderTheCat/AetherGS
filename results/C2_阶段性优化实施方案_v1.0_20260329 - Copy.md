#### 2.1 优化内容

**目标**: 减少 `get_cluster_AABB` 的重复计算

**问题分析**:
- 当前每 5 次迭代重新计算一次 cluster AABB
- 实际上 cluster 只在 densify 时才变化
- 存在大量冗余计算

**优化方案**:
```python
# trainer.py 中添加缓存机制
class TrainerState:
    def __init__(self):
        self.cluster_origin = None
        self.cluster_extend = None
        self.cluster_AABB_version = 0
        self.densify_version = 0
    
    def is_AABB_dirty(self):
        return self.cluster_AABB_version != self.densify_version
    
    def mark_AABB_clean(self):
        self.cluster_AABB_version = self.densify_version
```

**内部宏变量**:
```python
# zephgs/arguments.py
pp.C2_PHASE2_AABB_CACHE = True  # 阶段 2 优化开关
```

#### 3.1 优化内容

**目标**: 优化 `create_hierarchical_clusters` 的内存访问模式

**问题分析**:
- 当前代码多次调用 `contiguous()`
- 存在不必要的中间变量
- 内存布局不够优化

**优化方案**:
```python
# 优化前
xyz = xyz.contiguous()
scale = scale.contiguous()
rot = rot.contiguous()
# 多次 view 和 reshape

# 优化后
if not xyz.is_contiguous():
    xyz = xyz.contiguous()
if not scale.is_contiguous():
    scale = scale.contiguous()
if not rot.is_contiguous():
    rot = rot.contiguous()
# 减少中间变量，链式操作
```

**内部宏变量**:
```python
# zephgs/arguments.py
pp.C2_PHASE3_MEMORY_OPT = True  # 阶段 3 优化开关
```

### 阶段 4：并行化优化（预期：128s → 122s，-5%）

#### 4.1 优化内容

**目标**: 并行化 `hierarchical_frustum_culling` 中的循环

**问题分析**:
- 当前对每个 coarse cluster 串行处理
- GPU 利用率不足
- 可以批量处理 fine cluster 剔除

**优化方案**:
```python
# 优化前
for coarse_id in visible_coarse_ids:
    # 串行处理每个 coarse cluster
    fine_visibility = process_cluster(coarse_id)

# 优化后
# 批量处理所有 fine cluster
all_fine_origins = torch.stack([fine_origin[:, i] for i in visible_coarse_ids])
all_fine_extends = torch.stack([fine_extend[:, i] for i in visible_coarse_ids])
visibility = batch_frustum_culling(all_fine_origins, all_fine_extends)
```

**内部宏变量**:
```python
# zephgs/arguments.py
pp.C2_PHASE4_PARALLEL = True  # 阶段 4 优化开关
```

## 🎯 决策机制

每个阶段完成后，根据实际数据决定是否继续：

**继续标准**:
1. 性能提升达到预期的 80% 以上
2. 单元测试通过率 100%
3. 无质量下降（PSNR/SSIM 稳定）
4. 代码稳定性好（无崩溃、无内存泄漏）

**回滚标准**:
1. 性能提升低于预期的 50%

3. 代码不稳定

**组合优化决策**:
- 所有阶段完成后，综合评估是否合并
- 验证组合优化的协同效应
- 确保各阶段优化不冲突
