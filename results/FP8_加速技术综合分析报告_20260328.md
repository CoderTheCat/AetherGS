## 二、FP8 加速与 GPU 厂商兼容性分析

### 2.1 核心结论

**FP8 加速并非 NVIDIA 独占技术，但 NVIDIA 的支持最为完善和成熟。**

### 2.2 NVIDIA 方面的支持

根据网络搜索和官方文档 [1][2][3]：

- **硬件要求**：NVIDIA Hopper 架构（SM8.9）或更高版本
  - H100 GPU：首个支持 FP8 Tensor Core 的消费级/数据中心 GPU
  - B100/B200（Blackwell 架构）：支持 FP4 和 FP8
  - GeForce RTX 40 系列（Ada Lovelace）不支持 FP8 Tensor Core，会自动降级为 FP16

- **软件要求**：
  - NVIDIA 驱动 ≥ 550.44.03
  - CUDA Toolkit ≥ 12.4（推荐）
  - cuDNN ≥ 8.9
  - PyTorch ≥ 2.3

- **性能数据**（来自 NVIDIA 官方博客）：
  - Llama 3 8B：1.30x 加速
  - Llama 3.1 405B：1.53x 加速

### 2.3 AMD 方面的支持

根据 AMD 官方博客 [4]：

- **硬件支持**：AMD Instinct MI300 系列、MI325X、MI355X
- **软件支持**：ROCm 7.1 完全支持 FP8 训练
- **性能表现**：AMD 声称在 MLPerf Training v5.1 中使用 FP8 实现了高效训练
- **关键信息**：ROCm 是 AMD 的独立计算平台，不依赖 CUDA

### 2.4 Intel 方面的支持

根据 LiteGS 项目中 fused_ssim 子模块的代码 [5]：

- fused_ssim 支持 Intel XPU（通过 SYCL）
- 但 FP8 在 Intel GPU 上的支持尚不明确，需要进一步验证

### 2.5 总结表格

| GPU 厂商 | FP8 支持状态 | 软件平台 | 备注 |
|---------|-------------|---------|------|
| NVIDIA | ✅ 完整支持 | CUDA 12.4+ | Hopper+ 架构性能最佳 |
| AMD | ✅ 支持 | ROCm 7.1+ | MI300+ 系列 |
| Intel | ⚠️ 部分支持 | SYCL/XPU | 主要为推理优化 |

## 三、FP8 加速与 CUDA 版本的关系

### 3.1 核心结论

**FP8 加速对 CUDA 版本有要求，但并非只能用于 CUDA 12。CUDA 11.8 也有部分支持，但推荐使用 CUDA 12.4+ 以获得完整功能。**

### 3.2 CUDA 版本要求详解

根据官方文档 [6][7]：

| CUDA 版本 | FP8 支持状态 |
|----------|-------------|
| CUDA 11.8 | ⚠️ 部分支持（cuBLAS、TensorRT） |
| CUDA 12.0 | ✅ 基础支持 |
| CUDA 12.4 | ✅ 完整推荐版本 |
| CUDA 12.6+ | ✅ 最佳支持 |

### 3.3 关键要求

- **NVIDIA cuBLASDx**：需要 CUDA Toolkit 12.0 或更新 [6]
- **NVIDIA CUTLASS**：需要 CUDA Toolkit 12.9 [7]
- **TensorRT 10.x**：同时支持 CUDA 11.x 和 12.x，但 FP8 功能在 CUDA 12.x 上更稳定

### 3.4 跨平台注意事项

- **AMD GPU**：使用 ROCm 平台，不依赖 CUDA
- **Intel GPU**：使用 SYCL/oneAPI，不依赖 CUDA

### 3.5 CUDA 12.6 对老旧显卡的限制

**是的，CUDA 12.6 的前置要求会让部分老旧显卡无法获得 FP8 加速。**

根据网络搜索 [10][11]：

- **CUDA 12.6 最低要求 GPU 计算能力为 6.0 或更高** [10]
- 这意味着以下老旧显卡将**无法使用** CUDA 12.6 及其中包含的 FP8 特性：

| 显卡系列 | 计算能力 | CUDA 12.6 支持 | FP8 支持 |
|---------|---------|--------------|---------|
| Tesla K80 | 3.7 | ❌ 不支持 | ❌ 不支持 |
| GTX 1080/Ti (Pascal) | 6.1 | ✅ 支持 | ❌ 无 FP8 Tensor Core |
| GTX 1070 (Pascal) | 6.1 | ✅ 支持 | ❌ 无 FP8 Tensor Core |
| GTX 1180 (Turing) | 7.5 | ✅ 支持 | ❌ 无 FP8 Tensor Core |
| RTX 3090 (Ampere) | 8.6 | ✅ 支持 | ❌ 无 FP8 Tensor Core |
| RTX 4090 (Ada) | 8.9 | ✅ 支持 | ❌ 无 FP8 Tensor Core |
| H100 (Hopper) | 9.0 | ✅ 支持 | ✅ 支持 |
| B100 (Blackwell) | 12.0 | ✅ 支持 | ✅ 支持 |

**关键限制说明**：

1. **计算能力要求（6.0）**：CUDA 12.6 要求 SM 6.0（Pascal架构）或更高，这导致 Maxwell（5.0-5.2）和更早架构被淘汰

2. **FP8 Tensor Core 要求（8.9+）**：即使安装了 CUDA 12.6，**只有 Hopper（SM 8.9）或更新架构才能真正使用 FP8 Tensor Core 加速**

3. **软件降级行为**：在不支持 FP8 Tensor Core 的显卡上：
   - CUDA 12.6 仍可运行，但 FP8 操作会**自动降级为 FP16**
   - 用户可能误以为启用了 FP8，实际上没有任何加速效果

**LiteGS 项目中已有的显卡兼容情况**：

根据项目文档 [9]，LiteGS 主要测试的显卡为：
- NVIDIA RTX 3090（计算能力 8.6）- ❌ 无 FP8 Tensor Core
- NVIDIA RTX 4090（计算能力 8.9）- ❌ 无 FP8 Tensor Core

这意味着 LiteGS 官方测试的显卡**都无法真正获得 FP8 加速**，因为它们都不是 Hopper 架构！
