### 核心功能

**重要性分数计算**:
```python
def compute_importance_scores(...):
    # 梯度方差（反映学习活跃度）
    grad_var_xyz = torch.var(grad_xyz, dim=1)
    grad_var_opacity = torch.var(grad_opacity, dim=1)
    grad_var_scale = torch.var(grad_scale, dim=1)
    
    # 梯度幅值（避免梯度爆炸区域）
    grad_mag_xyz = torch.abs(grad_xyz).mean(dim=1)
    grad_mag_opacity = torch.abs(grad_opacity).mean(dim=1)
    grad_mag_scale = torch.abs(grad_scale).mean(dim=1)
    
    # 综合分数 = var / (1 + |grad|^2)
    grad_score = grad_var_score / (1.0 + grad_mag_score ** 2 + 1e-8)
    
    # 结合不透明度（70% 梯度 + 30% 不透明度）
    importance_score = 0.7 * grad_score + 0.3 * opacity_score
    
    # 归一化到 [0, 1]
    importance_score = (importance_score - min_score) / (max_score - min_score + 1e-8)
    
    return importance_score
```

**Top-K 选择**:
```python
# 70% 按重要性选择
importance_count = int(selected_clone_count * 0.7)
score_sorted_indices = torch.argsort(clone_scores, descending=True)

# 30% 随机选择（保持探索能力）
```
