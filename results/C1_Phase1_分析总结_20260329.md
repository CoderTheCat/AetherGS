### 核心功能

**1. 重要性分数计算**

```python
def compute_importance_scores(xyz, scale, rot, sh_0, sh_rest, opacity, 
                             grad_xyz=None, grad_opacity=None, grad_scale=None,
                             grad_threshold=0.0002):
    """
    基于梯度方差和幅值计算重要性分数
    - 梯度方差：反映学习活跃度（类似 Fisher 信息矩阵对角线）
    - 梯度幅值：反映学习强度
    - 不透明度：权重因子
    - 综合分数：0.7 * 梯度分数 + 0.3 * 不透明度分数
    """
```

**2. Top-K 选择**

```python
# 按重要性选择 top-K
importance_count = int(selected_clone_count * 0.7)  # 70% 按重要性
score_sorted_indices = torch.argsort(clone_scores, descending=True)
importance_selected = score_sorted_indices[:importance_count]

# 随机选择剩余部分
random_count = selected_clone_count - importance_count
remaining_indices = score_sorted_indices[importance_count:]
random_selected = remaining_indices[torch.randperm(len(remaining_indices))[:random_count]]
```

**3. 混合策略**

- **重要性引导**: 70%（利用已知信息）
- **随机探索**: 30%（保持探索能力）
- **理论依据**: Exploration-Exploitation Trade-off

4. **阈值过滤**: 梯度太小的点分数约 0.5（主要来自不透明度贡献）
